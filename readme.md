Dock & Drop 🖱️🪟

Dock & Drop is an interactive browser-based window snapping simulator inspired by macOS window management.

Built entirely with HTML, CSS, and vanilla JavaScript, this project recreates drag-and-drop window behaviour and dynamic snap zones in the browser — without frameworks.
📌 Overview

Dock & Drop simulates how desktop windows behave when dragged toward screen edges.

Users can:
	•	Drag windows freely across the viewport
	•	Snap windows to the left or right side of the screen
	•	Trigger snap logic based on edge proximity
	•	Experience smooth transitions between states

This project focuses on replicating real UI logic using core front-end principles.

⸻

🧠 Why I Built This

This project was created to:
	•	Strengthen understanding of DOM manipulation
	•	Practice mouse event handling (mousedown, mousemove, mouseup)
	•	Implement snap detection logic
	•	Build dynamic UI behaviour without relying on libraries
	•	Explore window management concepts inspired by macOS

It also complements my macOS utility project, Snaplet.

⸻

⚙️ Tech Stack

No frameworks. No libraries.
